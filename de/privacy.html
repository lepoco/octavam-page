Datenschutz

Octavam funktioniert ohne Konto, Werbung und Analyse.

  • MIDI-Dateien, Einstellungen und Fortschritte werden auf deinem Gerät gespeichert.
  • Bluetooth verbindet dein MIDI-Instrument.
  • Die gewählte Sprache der Website wird lokal im Browser gespeichert.
  • Diese Website verwendet keine Analyse und keine Cookies. GitHub Pages kann IP-Adressen gemäß der Datenschutzerklärung von GitHub erfassen.

Fragen: GitHub Issues.
